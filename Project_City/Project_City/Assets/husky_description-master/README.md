# husky_description

This package contains the description URDF model for the Husky robot. It is composed by three packages:
- ```husky_descritpion```: Contains the Xacro of the whole Husky robot.
- ```clearpath_platform_description```: Contains the Xacro macros of the Clearpath robots.
- ```clearpath_sensors_description```: Contains the Xacro macros of the Clearpath sensors.
- ```clearpath_viz```: Contains launchers for RViz visualizers (e.g. `ros2 launch clearpath_viz view_navigation.launch.py` to visualize the navigation demo)
